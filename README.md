## Kom i gang
Mesteparten av filene kjøres individuelt i egne mapper.

```bash
cd python
pip install -r requirements.txt
```

Deretter kan du kjøre en av demoene:

```bash
cd python/AI/NN
python spamtest.py
```

```bash
cd python/image_editing/filters
python main.py
```
