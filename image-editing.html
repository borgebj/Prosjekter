This project is a small collection of Python experiments around image processing. The focus is on understanding how filters work, how pixels are transformed, and how visual effects can be created with code.

It includes grayscale conversion, sepia effects, pixelation, ASCII-style rendering, and basic utilities for reading and displaying images.

What it shows

  • Python image manipulation with NumPy
  • Reusable filter logic
  • Quick visual experimentation
  • Practical examples of computer vision-style work

Typical tools

  • Python
  • NumPy
  • Pillow
