Luftkvalitet i Norge (IN2000)

Tilbake til hovedside

Dette er arbeid fra vår gruppe 5 i emnet IN2000 ved Universitetet i Oslo, som viser en fullverdig Android-app som henter og visualiserer sanntids luftkvalitetsdata i Norge ved hjelp av MET Norway API og Google Maps.

Appen gir brukerne oversikt over luftkvalitet, målinger, værinformasjon og interaktive kartutsnitt for lokasjoner i hele landet.

Oppgaver og ansvar var fordelt mellom teamet, hvorav jeg hadde hovedansvar for selve API'et og design av kart-siden, samt bruk av google maps API.

1. Parallell API-innsamling med Kotlin Coroutines (ViewModel.kt)

Denne funksjonen henter sanntids luftkvalitetsdata fra MET Norway API for alle målestasjoner i Norge parallelt. Ved å bruke Kotlin Coroutines med async og awaitAll utføres nettverkskallene samtidig i bakgrunnen for hver stasjon. Dette hindrer at hovedtråden (UI-tråden) henger seg opp, slik at appen forblir rask og responsiv for brukeren under lasting.

            } catch (e: Exception) {
                Log.e("ViewModel", "Error fetching data", e)
            }
        }
    }.awaitAll()
}

2. Robust modellmapping med Gson (Stasjon.kt)

Dette dataklasse-objektet definerer en målestasjon og brukes til å mappe innkommende JSON-data fra API-et ved hjelp av Gson. Ved å bruke @SerializedName(value = "name", alternate = ["station"]) sikrer vi at appen automatisk håndterer ulik nomenklatur eller endringer i feltnavn fra eksterne datakilder (f.eks. om stasjonsnavnet heter "name" eller "station") uten at deserialiseringen feiler.

@Parcelize
data class Stasjon(
    @SerializedName(
        value = "name",
        alternate = ["station"]
    )
    var name: String,
    @SerializedName("eoi")
    val eoi: String?,
    val longitude: Double?,
    val latitude: Double?,
    var verdier: HashMap<String, Double>? = HashMap()
) : Parcelable, Serializable
