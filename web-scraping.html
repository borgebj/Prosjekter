Web scraping

Tilbake til hovedside

Dette prosjektet er et praktisk eksempel på hvordan man kan bruke Python til å hente, analysere og strukturere informasjon fra nettsider.
Det starter med rå HTML og ender opp med et mer nyttig datasett som kan brukes videre i analyse og visualisering.

I prosjektet kombineres flere teknikker: HTTP-forespørsler, HTML-parsing, URL-filtrering, tabellutvinning, grafsøk, og databehandling gjennom Pandas. Samtidig får man en god følelse av hvordan dataflyten ser ut i et typisk scraping-prosjekt.

Det prosjektet går ut på

  • Hente HTML fra Wikipedia og andre nettsider.
  • Rydde opp i URL-er og filtrere relevante lenker.
  • Parser tabeller og KPI-er til strukturerte data.
  • Lage grafer basert på innsamlede statistikker.
  • Bruke BFS for å finne korte veier mellom artikler.
  • Cachere HTTP-responser for å spare tid og unngå overflødige kall.

Eksempelkode: hente og parse HTML

Første steg er å hente siden og la BeautifulSoup gjøre dokumentet lesbart for programmet. 

def get_html(url: str, params=None, output=None) -> str:
   headers = {
       "User-Agent": "BorgeWebScraper/1.0 (educational project)"
   }

   response = requests.get(url, params=params, headers=headers, timeout=10)
   response.raise_for_status()
   return response.text
html = get_html(url)
soup = BeautifulSoup(html, "html.parser")
links = soup.find_all("a", href=True)

Wiki Race: korteste vei via BFS

Et av de mest interessante delene er wiki-race-løsningsmetoden. Her behandles artikler som noder og lenker som kanter. BFS brukes fordi den finner korteste vei i antall hops når hver kant har lik kostnad. 

def find_path(start, finish, calls):
   queue = [(start, [start])]
   visited = {start}

   while queue:
       current, path = queue.pop(0)
       if current == finish:
           return path

       for url in get_links(current):
           if url not in visited:
               visited.add(url)
               queue.append((url, path + [url]))

Visualisering av analyse

Når dataene først er strukturert, kan de brukes i ekte analyse. I dette prosjektet visualiseres toppliste-data fra NBA-spillere med Matplotlib for å gi et tydelig og brukbart resultat.

Hvorfor dette er interessant

Dette er et godt eksempel på hvordan man kan bruke scraping ikke bare til å “hente tekst”, men til å lage en liten data-pipeline. HTML blir oversatt til en struktur, strukturen blir analysert, og det endelige resultatet kan brukes videre i modeller, rapporter eller visualiseringer.

Det som gjør prosjektet lærerikt er nettopp kombinasjonen av teknikker: nettverk, parsing, datahåndtering og algoritmisk tenkning i samme lille kodebase.
